# Modern Interactive Portfolio & DevStudio

Personal developer portfolio built by **Amos Solomanraj Nadar** as part of the **SkillMe Full Stack Engineer Virtual Internship**.

## Week 2 Milestone
- **Mobile-First Responsive Design:** Built with CSS media queries and tested down to `375px` mobile viewports with zero horizontal overflow.
- **Interactive Mobile Navigation:** Vanilla JavaScript hamburger menu toggle with automatic close on anchor link selection.
- **Dynamic Project Showcase & Filtering:** Project cards rendered dynamically from a JavaScript data array (`script.js`) with live category filters (`All Projects`, `Firebase / PWA`, `Automation`, `JavaScript`).

## Week 1 Milestone
- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `footer`).
- Consistent design tokens using CSS variables (`:root`).
- Flexbox layout with smooth in-page anchor scrolling across About, Stack, Projects, and Contact sections.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox, Media Queries, CSS Variables), Vanilla JavaScript (ES6+)
- **Backend & Automation Tools Showcased:** Firebase (PWAs), Google Apps Script, Google Sheets, PowerShell, OBS Studio
